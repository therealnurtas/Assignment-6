# Assignment 6. jQuery (Selectors, Effects, Animations)

**Name:** YEERKEBAY NURTAS  **Group:** IT-2507

Birthday party in a house: 4 rooms, 21 guests, find the thief with jQuery. Only jQuery 3.7.1 is used (no other libraries, no onclick attributes, no CSS transitions or animations).

## Structure
- `index.html` - start page with links to both tasks
- `task1/` - Task 1. Selector Detective (array, page built from it, 20 cases)
- `task2/` - Task 2. The party in motion (copy of Task 1 + spotlight, guest card, move, sort by time)
  - `index.html`, `style.css`, `script.js` in each folder

## How to run
Open `index.html` in a browser (internet is needed for jQuery CDN and the Open Peeps avatars), or use GitHub Pages: Settings -> Pages -> Deploy from branch `main` / root.

## Tools used
Selectors (id, class, attribute, `:has()`, `:not()`, `:last-child`, `:nth-child()`), `filter()`, `next()`, `prev()`, `nextAll()`, `closest()`, `add()`, `insertAfter()`, `fadeIn()`, `fadeOut()`, `remove()`, `fadeTo()`, `animate()`, `stop()`, `offset()`, `clone()`, `css()`, `append()`, `on()`.
